# 벤치마킹 노트

규칙 3(이미 수익화된 프로젝트를 참고)에 따라 조사한 내용과, 이 사이트에 반영한 점입니다.

## 참고한 서비스

| 서비스 | 규모·수익 구조 | 참고한 점 |
|---|---|---|
| [Omni Calculator](https://www.omnicalculator.com/omni-by-the-numbers) | 월 방문 약 1,600만~2,000만, 광고(애드센스 → Ad Manager) 중심. 월 2만 방문에서 성장했다고 [Google 퍼블리셔 사례](https://www.google.co.in/ads/publisher/stories/omni_calculator/)에 소개됨 | 계산기 1개 = 페이지 1개, 계산기 아래 공식·설명·FAQ, 유입의 약 절반이 구글 자연검색 |
| [Calculator.net](https://ahrefs.com/top/calculator.net) | Semrush 추정 월 5천만 방문, 광고 수익 | 금융 계산기(대출·이자·급여)를 핵심 카테고리로 둠 |
| 국내 계산기 사이트(glasswallet, calcnara 등) | 애드센스 | 2026년 요율 기준일 명시, "추정치·법적 효력 없음" 고지 |

금융·보험 분야는 광고 단가(RPM)가 높은 카테고리로 알려져 있어(미국 기준 약 $10 RPM이라는 계산기 기본값 등), 첫 계산기 묶음을 급여·대출·저축·부동산으로 골랐습니다.
위 트래픽·수익 수치는 제3자 추정치이며 검증된 값이 아닙니다.

## 반영한 것

- 계산기마다 독립 URL, 제목에 검색어(예: "2026 연봉 실수령액 계산기") 포함
- 계산기 아래 계산 방법·FAQ·참고 자료·업데이트 날짜 → 정보성 콘텐츠 + FAQPage 구조화 데이터
- 입력값이 URL에 남아 결과 공유 가능 (Omni의 공유 링크 방식)
- 연봉 구간별 실수령액 "표" 페이지 — 표 형태 검색어 수요 대응
- 차별점: 소득세를 근사식이 아닌 **국세청 간이세액표 원문(646구간)** 으로 계산
- 광고 자리는 계산 결과 바로 아래와 본문 아래 (계산 흐름을 방해하지 않는 위치)
