# 벤치마킹 노트

규칙 3(이미 수익화된 프로젝트를 참고)에 따라 조사한 내용과, 앱에 반영한 점입니다.

## 2026-10-20 방향 전환
- 처음에는 한국 금융 계산기 웹사이트(광고 수익)를 만들었으나, 연봉 실수령액 등 일반 계산기는
  사람인·oursupporter·glasswallet 등 경쟁이 매우 많아 **3.3% 프리랜서·N잡러** 틈새로 좁혔다.
- 이후 사용자 요청에 따라 웹이 아닌 **단독 앱(Expo, Android·iOS)** 으로 전환했다.

## 핵심 벤치마크: 삼쩜삼 (자비스앤빌런즈)

| 항목 | 내용 (출처: 언론 보도·회사 발표, 독립 검증 아님) |
|---|---|
| 대상 | 3.3% 원천징수 프리랜서·N잡러의 종합소득세 환급 |
| 규모 | 누적 가입자 2022.4 1,000만 → 2024.5 2,100만, 누적 환급신고액 2조원 이상 |
| 매출 | 2022년 496억원, 2024년 상반기 777억원 |
| 수익 구조 | 환급 신고 대행 시 수수료 (기한후신고 등 유료 서비스) |
| 리스크 | 부당 환급 시 이용자 가산세, 세무사회와 무자격 세무대리 분쟁(2023 무혐의) |

**시사점**
- 3.3% 프리랜서의 "얼마 돌려받나"는 검증된 대규모 수요다.
- 삼쩜삼은 홈택스 연동·대리 신고·수수료 모델이라 회원가입과 개인정보 제공이 필요하다.

**프리셈의 차별점 (반영한 것)**
- 회원가입·서버·추적 없이 **기기 안에서만** 계산 (개인정보 부담 없음, 오프라인 동작)
- 신고 대행이 아닌 **미리 계산·판단 도구**: 환급 예상, 단순/기준경비율 판정, N잡 추가 납부, 피부양자 탈락과
  지역보험료, 근로장려금, 8.8% 분리/종합 비교 — 삼쩜삼이 다루지 않거나 흩어져 있는 판단을 한곳에
- 법령 원문(간이세액표 PDF, 건보 별표 HWP, law.go.kr API)에서 직접 수치를 가져오고 출처를 표시
- 수입 기록 → 계산기 자동 반영, 세금 일정 알림으로 연중 사용 동기 제공 (5월에만 쓰는 앱이 되지 않게)
