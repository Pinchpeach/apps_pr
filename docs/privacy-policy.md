# 프리셈 개인정보처리방침

시행일: 2026-10-20

프리셈(이하 "앱")은 프리랜서·N잡러를 위한 세금·건강보험 계산 앱입니다.

## 1. 수집하는 개인정보
앱은 **어떠한 개인정보도 수집하거나 외부로 전송하지 않습니다.**

- 회원가입·로그인이 없습니다.
- 사용자가 입력한 금액(수입, 급여, 세액 등)은 계산과 다음 실행 시 입력값 복원을 위해 **사용자의 기기 안에만** 저장됩니다.
- 앱은 서버와 통신하지 않으며, 광고·분석·추적 도구를 사용하지 않습니다.
- 세금 일정 알림을 켜면 알림이 **기기 안에서** 예약됩니다. 푸시 서버나 기기 식별 토큰을 사용하지 않습니다.

## 2. 기기에 저장되는 정보의 삭제
기기에 저장된 입력값은 앱을 삭제하거나 기기 설정에서 앱 데이터를 지우면 모두 삭제됩니다.

## 3. 외부 링크
앱 안의 법령·기관 안내 링크를 누르면 해당 외부 웹사이트(국가법령정보센터, 국세청, 국민건강보험공단 등)로 이동하며, 그 사이트의 개인정보처리방침이 적용됩니다.

## 4. 변경
이 방침이 바뀌면 앱 업데이트와 함께 이 문서를 갱신합니다. 광고나 분석 도구를 도입하게 되면 사전에 이 문서에 수집 항목을 밝힙니다.
